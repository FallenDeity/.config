# gh-dash Cheat Sheet

gh-dash is an interactive terminal dashboard extension for GitHub CLI (`gh dash`).

---

## Navigation

| Keybinding                                         | Action                                         |
| :------------------------------------------------- | :--------------------------------------------- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Switch between **PRs** and **Issues** sections |
| <kbd>J</kbd> / <kbd>K</kbd> *(or Arrows)*          | Navigate up / down list                        |
| <kbd>H</kbd> / <kbd>L</kbd>                        | Navigate left / right sub-views                |
| <kbd>G</kbd> / <kbd>Shift</kbd> + <kbd>G</kbd>     | Jump to Top / Bottom of active list            |
| <kbd>/</kbd>                                       | Filter items in active view                    |
| <kbd>R</kbd>                                       | Refresh active section / data                  |

---

## Pull Requests Actions

| Keybinding       | Action                         |
| :--------------- | :----------------------------- |
| <kbd>Enter</kbd> | View PR details in sidebar     |
| <kbd>O</kbd>     | Open PR in default web browser |
| <kbd>C</kbd>     | Checkout PR branch locally     |
| <kbd>D</kbd>     | View PR diff in pager          |
| <kbd>M</kbd>     | Merge PR                       |
| <kbd>Y</kbd>     | Copy PR URL to clipboard       |

---

## Issues Actions

| Keybinding       | Action                            |
| :--------------- | :-------------------------------- |
| <kbd>Enter</kbd> | View issue details in sidebar     |
| <kbd>O</kbd>     | Open issue in default web browser |
| <kbd>Y</kbd>     | Copy Issue URL to clipboard       |
| <kbd>C</kbd>     | Close issue                       |
| <kbd>R</kbd>     | Reopen issue                      |

---

## Global Commands

| Keybinding                                    | Action                                 |
| :-------------------------------------------- | :------------------------------------- |
| <kbd>?</kbd>                                  | Open interactive keybinding help modal |
| <kbd>S</kbd>                                  | Search GitHub across repos             |
| <kbd>Q</kbd> / <kbd>Ctrl</kbd> + <kbd>C</kbd> | Quit gh-dash                           |
