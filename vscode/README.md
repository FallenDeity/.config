# Visual Studio Code Configuration

Not synced by the powershell script, but you can use this as a reference for your own configuration. I have mine synced with the settings sync feature of vscode, but if you want to use this repo as a reference, feel free to do so. The settings are in `vscode/settings.json`. The extensions are listed in `vscode/extensions.txt`, you can install them by running the following command:

```pwsh
$ code --install-extension <extension-id>
```
