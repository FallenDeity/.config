# Posting Cheat Sheet

Posting is an interactive TUI API client for HTTP requests configured with Catppuccin Mocha.

---

## Navigation

| Keybinding                                                      | Action                                      |
| :-------------------------------------------------------------- | :------------------------------------------ |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd>              | Move focus between request builder sections |
| <kbd>Ctrl</kbd> + <kbd>J</kbd> / <kbd>Ctrl</kbd> + <kbd>K</kbd> | Navigate tabs / fields                      |
| <kbd>Ctrl</kbd> + <kbd>Enter</kbd>                              | **Send Request**                            |
| <kbd>Ctrl</kbd> + <kbd>S</kbd>                                  | Save Request to collection                  |
| <kbd>Ctrl</kbd> + <kbd>O</kbd>                                  | Open collection / environment browser       |

---

## Request Editing

| Keybinding                     | Action                    |
| :----------------------------- | :------------------------ |
| <kbd>Ctrl</kbd> + <kbd>H</kbd> | Focus Headers editor      |
| <kbd>Ctrl</kbd> + <kbd>B</kbd> | Focus Request Body editor |
| <kbd>Ctrl</kbd> + <kbd>P</kbd> | Focus Parameters editor   |
| <kbd>Ctrl</kbd> + <kbd>A</kbd> | Focus Auth settings       |

---

## Global Operations

| Keybinding                                    | Action                              |
| :-------------------------------------------- | :---------------------------------- |
| <kbd>F1</kbd> *(or <kbd>?</kbd>)*             | Show interactive help & keybindings |
| <kbd>Ctrl</kbd> + <kbd>C</kbd> / <kbd>Q</kbd> | Exit Posting                        |
